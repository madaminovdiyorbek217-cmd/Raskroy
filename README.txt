ОНЛАЙН-РАСКРОЙ: отдельный сайт

Как опубликовать
1. Загрузите ВСЮ эту папку на хостинг так, чтобы index.html лежал в корне сайта
   (Cloudflare Pages, Netlify, GitHub Pages или обычный хостинг).
2. Замените YOUR-DOMAIN.com на ваш адрес в файлах: index.html, robots.txt, sitemap.xml.
3. Файлы _headers (Cloudflare/Netlify) и .htaccess (Apache) включают защитные заголовки.

Что где
index.html           страница с расчётом
css/style.css        оформление
js/raskroy-core.js   алгоритм раскроя
js/raskroy.js        интерфейс: материалы, детали, карты листов, экспорт
js/raskroy-worker.js расчёт в фоне
js/fabric-core.js    алгоритм раскладки ткани на рулон
js/fabric.js         раздел «Ткань»: интерфейс и расчёт метров
js/fabric-i18n.js    тексты раздела «Ткань» на трёх языках
js/ui.js             переключатель темы (светлая, тёмно-синяя, чёрная)
js/i18n.js           языки RU / EN / UZ: все тексты и переводы лежат здесь

Название сайта «Раскрой онлайн» меняется в index.html (в шапке и в <title>).
После правок CSS или JS поменяйте число в ?v=3 в index.html, чтобы браузеры загрузили новую версию.
Данные проекта хранятся только в браузере пользователя, на сервер ничего не отправляется.

Языки: выбор запоминается в браузере. Чтобы поправить или добавить перевод, откройте js/i18n.js: у каждого текста один ключ и три значения (ru, en, uz).

Работы: каждая вкладка под шапкой это отдельная работа со своими материалами и деталями. Всё хранится в браузере (localStorage, ключ rk-projects-v1).

Импорт из Базиса: кнопка «Импорт из Базис» в разделе «Детали» читает файлы .project (выгрузка скрипта GibLab из Базиса), CSV, TXT, JSON и Excel (.xlsx), создаёт новую работу с материалами и деталями. Колонки определяются по заголовкам: Название, Материал, Толщина, Длина, Ширина, Количество, Текстура/Поворот, Кромка длина 1/2, Кромка ширина 1/2.

ПРИЛОЖЕНИЕ (PWA): установка и работа без интернета
Сайт устанавливается как приложение: в Chrome/Edge на ПК кнопка «Установить приложение» в шапке, на Android в настройках острова, на iPhone: «Поделиться» → «На экран Домой».
После первого открытия всё работает без интернета: расчёт, импорт, работы, копии. Данные остаются на устройстве.
Условия: сайт должен открываться по https:// (на хостинге это так по умолчанию). Двойной клик по файлу из папки (file://) приложением не станет.
Открытие файлов: в установленном приложении на ПК (Chrome/Edge) файлы .project, .csv, .xlsx и др. можно открыть через «Открыть с помощью → Раскрой». Файл можно также перетащить в окно.
Ярлыки: долгое нажатие на значок приложения даёт «Новая работа», «Импорт из Базис», «Мои работы».
Копия работ: «Копия работ» и «Из копии» в разделе «Работы» сохраняют и возвращают все работы одним файлом.
ОБНОВЛЕНИЕ САЙТА: после правок файлов поменяйте номер версии в трёх местах одновременно: ?v=… в index.html, VERSION в js/raskroy.js и VERSION в sw.js. Пользователи увидят плашку «Доступна новая версия» и нажмут «Обновить».
Файлы приложения: manifest.webmanifest (название, значки, ярлыки), sw.js (офлайн-кэш), js/app.js (установка, обновления, открытие файлов), icons/ (значки).

GITHUB PAGES
Файл .nojekyll нужен, чтобы GitHub отдавал все файлы как есть (включая папку .well-known). Файлы _headers и .htaccess на GitHub Pages не действуют: защита страницы (CSP) уже задана внутри index.html.
Адрес будет вида https://ИМЯ.github.io/РЕПОЗИТОРИЙ/ (если репозиторий называется ИМЯ.github.io, то https://ИМЯ.github.io/). Все пути в сайте относительные, поэтому работает и в подпапке.

РАЗДЕЛ «ТКАНЬ»
Переключатель «Плиты | Ткань» вверху. В режиме «Ткань» считается, сколько метров ткани уйдёт на мягкую мебель: вводятся ширина рулона и размеры деталей (длина вдоль рулона, ширина поперёк), сайт укладывает детали на рулон и показывает метраж, использование ткани и чертёж с линейкой.
Настройки: кромка рулона, припуск на шов, зазор, раппорт (шаг рисунка, поворот при этом выключается), запас в процентах, округление заказа, цена за метр. Несколько тканей (основная, подкладка) идут отдельными вкладками, внизу итог по всем.
Данные хранятся в браузере (ключ rk-fabric-v1) и входят в «Копию работ». Ярлык приложения «Раскрой ткани» и адрес ?tool=fabric открывают этот режим сразу.

ОФОРМЛЕНИЕ (фон и цвета)
Кнопка с палитрой в шапке (на телефоне: настройки острова → «Оформление») открывает панель: тема (светлая, тёмно-синяя, чёрная), 24 готовых фона (светлые и тёмные, есть градиенты), 15 цветов акцента и «Свой цвет» для фона и акцента. Выбор виден сразу и запоминается в браузере (ключ rk-look). «Сбросить оформление» возвращает цвета темы.
Если выбрать фон другого тона (тёмный при светлой теме), тема переключается сама, чтобы текст читался. Слишком «средний» свой цвет сайт слегка подправляет по яркости по той же причине.
Новые файлы: js/look.js (панель), js/look-i18n.js (тексты на трёх языках). Список готовых фонов и акцентов лежит в js/theme-init.js (массивы BG и ACC): туда можно добавлять свои.
